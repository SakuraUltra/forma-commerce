# FORMA v0.1.0

The first portfolio release of **FORMA**, a boutique ecommerce storefront and reusable **Next.js / React / TypeScript** template. This release can be explored directly on GitHub or through the downloadable presentation; no website deployment is needed.

## Start here

- **Watch:** the README includes a 16-second animated overview. Download `forma-walkthrough.mp4` for the 32-second version.
- **Present:** download `forma-v0.1.0-showcase.zip`, extract it and open `index.html`. The presentation bundles screenshots, video, an animated preview and a bilingual case study, so its media can be viewed offline. External source links require internet access.
- **Interact:** use the source code archive below, or clone the `v0.1.0` tag. With Node.js 22.22+, run `npm ci` and `npm run dev`, then open `http://localhost:3000`. Dependencies, build-time Google fonts and product photography require internet access.
- **Read:** [project case study](https://github.com/SakuraUltra/my-shop/blob/v0.1.0/docs/showcase.md) and [中文说明](https://github.com/SakuraUltra/my-shop/blob/v0.1.0/docs/README.zh-CN.md).

## Included

- FORMA's warm ivory and olive identity, responsive layouts and light/dark themes.
- A shared catalog of 12 sample products, URL-based filters, sorting and keyboard search.
- Variant selection, a persistent cart, catalog-based price and quantity checks, and guest demo checkout.
- Saved order snapshots, order history, storage-error handling and an interactive delivery simulation.
- 27 automated test cases and GitHub Actions checks for lint, tests and the production build.
- MIT-licensed application code, bilingual setup documentation and source-linked engineering decisions.

The animation and video are montages of captured working-interface screens, not real-time recordings. The presentation is a static showcase; interactive shopping runs in the local app.

## Demo scope

No real payments, accounts, emails or shipments are involved. Use the fictional address provided. Orders stay in the current browser; there is no shared inventory reservation or production transaction backend. Product photographs come from Unsplash and are separate from the code's MIT license.
